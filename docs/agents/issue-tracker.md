# Issue tracker

For the capture-first two-currency spec, the owner approved the Markdown files in [the local issues directory](../../.scratch/capture-first-two-currencies/issues/) as the tracker. The [spec](../../.scratch/capture-first-two-currencies/spec.md) defines scope and the test seam.

Read each ticket's `Blocked by` field to find ready work. Record implementation commits and verification in the ticket. Check criteria only after observing the outcome; keep device-only checks open when unavailable. Use `complete` when every criterion is met, or `implemented; pending manual verification` when code and automated checks pass but device/client checks remain.

Merge work into `capture-first-two-currencies`. Ticket closure is a committed status/checkbox update; this workflow requires no external issue or PR. Record integration checks in [validation.md](../../.scratch/capture-first-two-currencies/validation.md).
